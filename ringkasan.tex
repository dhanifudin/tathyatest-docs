\chapter*{RINGKASAN}
\addcontentsline{toc}{chapter}{RINGKASAN}

Pengujian aplikasi web di Jurusan Teknologi Informasi Politeknik Negeri Malang menghadapi tantangan dalam memastikan kualitas aplikasi akademik seperti Kompen, Jayanti, dan Whistleblower. Alat automation testing seperti Selenium, Cypress, dan Playwright masih memerlukan pembuatan test case manual yang menjadi bottleneck. TathyaTest direncanakan hadir sebagai test case generator otomatis yang melakukan crawling DOM ter-render (Playwright), membangun model elemen dan matriks akses per peran pengguna (RBAC), lalu menghasilkan dan mengeksekusi test case fungsional secara otomatis. Penelitian ini mengukur efektivitas TathyaTest dalam menghasilkan test case otomatis dan mendeteksi cacat fungsional, meningkatkan cakupan pengujian fungsional (cakupan model elemen dan rute, mencakup CRUD, autentikasi, dan akses modul), dan memvalidasi ekspektasi fungsional secara konsisten lintas browser. Metode Prototyping digunakan secara iteratif dari prototipe CRUD sederhana, perbaikan berdasarkan umpan balik, hingga integrasi Playwright untuk cross-browser testing (Chrome, Firefox, WebKit) dan evaluasi pada aplikasi studi kasus berarsitektur MVC dan RBAC (Laravel Blade, Laravel Inertia-React, dan SauceDemo sebagai pembanding). Penelitian dibatasi pada aplikasi web MVC dengan fokus pengujian fungsional berbasis UI. Analisis data menggunakan pendekatan kuantitatif (cakupan pengujian, skor mutasi, efisiensi waktu). Luaran meliputi prototipe TathyaTest TKT 4, artikel ilmiah pada Jurnal Teknologi Informasi dan Ilmu Komputer (JUTI), dan Hak Cipta. Penelitian ini berkontribusi pada Software Testing dan Quality Assurance melalui metode otomatis test case generation berbasis crawling DOM ter-render dan pemetaan elemen-ke-test-case, menjadi pondasi roadmap lima tahun pengembangan TathyaTest dengan integrasi AI dan machine learning.
