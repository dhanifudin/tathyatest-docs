\noindent
\textbf{Catatan Justifikasi:}

\begin{enumerate}
    \item \textbf{Biaya Sewa Alat (15\%):} Sewa server dan cloud storage diperlukan untuk deployment dan pengujian aplikasi web secara kontinu selama 8 bulan penelitian. Server digunakan untuk menjalankan aplikasi yang akan diuji, sedangkan cloud storage untuk menyimpan dataset, hasil pengujian, dan backup data penelitian.

    \item \textbf{Biaya Bahan (40\%):} Lisensi IDE WebStorm diperlukan untuk 4 anggota tim peneliti dalam mengembangkan TathyaTest menggunakan TypeScript. Hardisk eksternal untuk backup data penelitian, source code, dataset, dan dokumentasi. ATK dan printout untuk dokumentasi dan administrasi penelitian.

    \item \textbf{Biaya Perjalanan (20\%):} Transportasi diperlukan untuk pengumpulan konfigurasi dan data uji aplikasi studi kasus, uji coba prototipe dengan pengguna, dan konsultasi dengan pakar software testing untuk validasi penelitian.

    \item \textbf{Biaya Lain-lain (25\%):} Honorarium pembantu peneliti untuk 4 mahasiswa yang terlibat dalam implementasi dan testing TathyaTest. Biaya publikasi jurnal (JUTI) dan pendaftaran HKI merupakan luaran wajib penelitian. Dokumentasi dan komunikasi untuk mendukung kelancaran pelaksanaan penelitian.
\end{enumerate}
