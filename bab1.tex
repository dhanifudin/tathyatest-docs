\chapter{PENDAHULUAN}\label{bab-i-pendahuluan}

\section{Latar Belakang}\label{latar-belakang}

Perkembangan pesat dalam teknologi informasi telah memberikan dampak besar pada berbagai sektor, termasuk dunia pendidikan. Di perguruan tinggi, aplikasi berbasis web telah menjadi alat penting dalam menyelenggarakan kegiatan akademik dan administrasi, seperti sistem manajemen akademik, pengelolaan keuangan, dan pelaporan data. Di Jurusan Teknologi Informasi, aplikasi-aplikasi seperti Kompen, Jico, Jayanti, dan Whistleblower digunakan oleh mahasiswa, dosen, dan staf untuk kegiatan yang sangat krusial. Meskipun aplikasi-aplikasi ini telah memberikan banyak kemudahan, tantangan utama yang dihadapi adalah memastikan aplikasi-aplikasi tersebut berfungsi dengan baik dan selalu tersedia tanpa gangguan.

Gangguan dalam ketersediaan aplikasi atau kesalahan dalam fungsionalitas dapat menurunkan kualitas layanan dan berdampak pada pengalaman pengguna. Sebagai contoh, downtime pada aplikasi akademik seperti Kompen dapat menghambat akses mahasiswa dan dosen untuk mengelola informasi akademik mereka. Selain itu, kesalahan dalam pengolahan data yang terjadi pada aplikasi seperti Jayanti atau Whistleblower dapat merugikan pihak terkait dan mempengaruhi operasional kampus secara keseluruhan. Oleh karena itu, penting bagi aplikasi-aplikasi berbasis web di Jurusan Teknologi Informasi untuk selalu diuji secara berkala guna memastikan bahwa mereka berfungsi sesuai dengan yang diharapkan dan siap digunakan setiap saat.

Salah satu metode yang paling efektif untuk memastikan kualitas aplikasi perangkat lunak adalah dengan menggunakan automation testing. Automation testing mengacu pada penggunaan alat dan skrip otomatis untuk menjalankan pengujian perangkat lunak tanpa intervensi manual. Menurut \cite{santhosh2023automation}, automation testing menawarkan berbagai keuntungan, termasuk penghematan waktu, pengurangan kesalahan manusia, dan kemampuan untuk menjalankan pengujian secara berulang tanpa menambah biaya yang signifikan. Dalam konteks pengujian aplikasi berbasis web, penggunaan alat automation testing sangat berguna untuk menguji berbagai skenario pengguna dan fungsionalitas aplikasi secara cepat dan akurat.

Namun, meskipun terdapat berbagai alat untuk automation testing seperti Selenium, Cypress, dan Playwright, tantangan terbesar adalah bagaimana mengotomatisasi pembuatan test case yang relevan dengan fungsionalitas aplikasi yang diuji. \cite{alsaeedi2020} dalam penelitiannya mengungkapkan bahwa meskipun berbagai alat pengujian otomatis ada, kebanyakan dari alat ini masih memerlukan input manual untuk mendefinisikan skenario pengujian, yang pada gilirannya menambah waktu dan beban kerja pengujian. Oleh karena itu, diperlukan sebuah solusi yang dapat mengotomatisasi test case generation secara efisien untuk memastikan bahwa pengujian dilakukan secara lebih cepat dan lebih menyeluruh.

TathyaTest: Test Case Generator Otomatis merupakan solusi yang dikembangkan untuk mengatasi masalah ini. TathyaTest dirancang untuk menghasilkan test case otomatis berdasarkan crawling aplikasi dan elemen-elemen yang ada pada halaman web aplikasi. Dengan memanfaatkan dataset internal aplikasi seperti Kompen, Jico, Jayanti, dan Whistleblower, TathyaTest dapat disesuaikan untuk menghasilkan test case yang relevan dengan masing-masing aplikasi, sehingga pengujian dapat dilakukan dengan lebih cepat dan lebih komprehensif. Penelitian yang dilakukan oleh \cite{kassie2020} menunjukkan bahwa otomatisasi pembuatan test case membantu mengidentifikasi bug lebih cepat dan meningkatkan cakupan pengujian. Hal ini sejalan dengan tujuan pengembangan TathyaTest, yang tidak hanya mengotomatiskan pembuatan test case tetapi juga meningkatkan efisiensi pengujian di Jurusan Teknologi Informasi.

Dengan adanya TathyaTest, proses pengujian dapat dilakukan secara lebih efisien, mengurangi ketergantungan pada pengujian manual yang memakan waktu dan sering kali tidak lengkap. Selain itu, TathyaTest akan memberikan manfaat yang signifikan dalam mempermudah pengujian aplikasi berbasis web, khususnya di lingkungan pendidikan tinggi, dengan memfokuskan pada pengujian fungsional aplikasi yang digunakan oleh mahasiswa dan dosen di Jurusan Teknologi Informasi. Penelitian ini diharapkan dapat memberikan kontribusi besar dalam meningkatkan kualitas aplikasi yang digunakan di perguruan tinggi dan memberikan dasar yang kuat bagi pengembangan alat pengujian perangkat lunak otomatis di masa depan.

\section{Rumusan Masalah}\label{rumusan-masalah}

\begin{enumerate}
    \item Bagaimana efektivitas TathyaTest dalam menghasilkan test case otomatis untuk pengujian aplikasi berbasis web,  berdasarkan dataset internal aplikasi yang ada?
    \item Sejauh mana TathyaTest dapat meningkatkan cakupan pengujian aplikasi berbasis web dengan menghasilkan test case pengujian fungsional?
    \item Bagaimana TathyaTest dapat memvalidasi ekspektasi fungsional aplikasi berbasis web berdasarkan dataset internal yang ada, seperti memastikan login berhasil, data dapat disimpan, dan modul dapat diakses dengan benar?
\end{enumerate}

\section{Batasan Masalah}\label{batasan-masalah}

Untuk memfokuskan penelitian dan memastikan hasil yang optimal, batasan masalah dalam penelitian ini meliputi:

\begin{enumerate}
    \item Penelitian ini terbatas pada aplikasi berbasis web dengan arsitektur MVC (Model-View-Controller).
    \item Pengujian difokuskan pada fungsionalitas aplikasi yang mencakup operasi CRUD (Create, Read, Update, Delete), autentikasi pengguna, dan akses modul.
    \item Dataset yang digunakan untuk pengujian berasal dari aplikasi internal Jurusan Teknologi Informasi, yaitu Kompen, Jico, Jayanti, dan Whistleblower.
    \item TathyaTest hanya menghasilkan test case untuk pengujian fungsional berbasis UI (User Interface) dan tidak mencakup pengujian non-fungsional seperti performance testing, security testing, atau load testing.
    \item Pengujian dilakukan pada browser modern (Chrome, Firefox, dan WebKit) menggunakan Playwright sebagai automation testing framework.
    \item Penelitian ini tidak mencakup pengujian untuk aplikasi mobile native atau aplikasi desktop.
\end{enumerate}

\section{Tujuan Penelitian}\label{tujuan-penelitian}

\begin{enumerate}
    \item Mengukur efektivitas TathyaTest dalam menghasilkan test case otomatis yang mencakup seluruh fungsionalitas aplikasi berbasis web, dengan memanfaatkan dataset internal aplikasi seperti Kompen, Jico, Jayanti, dan Whistleblower.
    \item Menilai seberapa baik TathyaTest dapat meningkatkan cakupan pengujian aplikasi berbasis web, dengan menghasilkan test case yang mencakup elemen-elemen penting seperti login, pengeditan data, akses modul, dan fungsionalitas lainnya, berdasarkan dataset internal aplikasi yang ada.
    \item Mengevaluasi apakah TathyaTest dapat memvalidasi ekspektasi fungsional aplikasi berbasis web berdasarkan dataset internal yang ada, seperti memastikan login berhasil, data dapat disimpan, dan modul dapat diakses dengan benar.
\end{enumerate}
