\item Objek Penelitian: Aplikasi berbasis web dengan arsitektur MVC dan kontrol akses berbasis peran (RBAC) sebagai studi kasus evaluasi -- aplikasi Laravel Blade dan Laravel Inertia-React, serta aplikasi eksternal SauceDemo sebagai pembanding (baseline); aplikasi internal Jurusan Teknologi Informasi (Kompen, Jayanti, Whistleblower) menjadi motivasi awal dan direncanakan untuk tahap penelitian lanjutan.

\item Masa Pelaksanaan: \lamaPenelitian\ bulan (\bulanTahun)

\item Biaya yang Diusulkan: Rp \biayaDiusulkan,-

\item Lokasi Penelitian: Jurusan Teknologi Informasi, Politeknik Negeri Malang

\item Instansi Lain yang Terlibat: Tidak ada

\item Temuan yang Ditargetkan (TKT): Prototipe TathyaTest dengan target TKT 4, yaitu validasi komponen dalam lingkungan laboratorium. TathyaTest direncanakan dapat digunakan untuk pengujian aplikasi web berbasis crawling DOM ter-render (Playwright), meskipun masih dalam skala terbatas (aplikasi studi kasus).

\item Kontribusi Mendasar pada Suatu Bidang Ilmu: Penelitian ini memberikan kontribusi pada bidang Software Testing dan Quality Assurance melalui pengembangan metode otomatis untuk test case generation yang memanfaatkan crawling DOM ter-render dan ekstraksi elemen HTML pada konteks browser. TathyaTest mengotomatisasi proses ini dengan membangun model elemen dan matriks akses per peran pengguna untuk menghasilkan test case yang lebih relevan dan kontekstual.

\item Jurnal Ilmiah yang Menjadi Sasaran: Jurnal Teknologi Informasi dan Ilmu Komputer (JUTI).

\item Rencana Luaran HKI: Hak Cipta untuk prototipe TathyaTest dengan status Granted.
